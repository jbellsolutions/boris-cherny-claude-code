Drop-In Setup

Install Boris's configuration into any project.

The setup includes agents, commands, hooks, permissions, and a CLAUDE.md template — all ready to use. Run one command and the full setup is in your project.

5 Custom Agents

  • code-reviewer — Multi-agent PR review
  • build-validator — Typecheck, lint, test, build
  • code-simplifier — Post-implementation cleanup
  • verify-app — E2E verification
  • worktree-worker — Isolated parallel worker

4 Slash Commands

  • /commit-push-pr — One-command ship
  • /babysit — Auto-address PR reviews
  • /feature-dev — Planning-first workflow
  • /techdebt — Find and fix duplication

Hooks & Permissions

  • PostToolUse auto-format on every edit
  • Pre-allowed safe commands (test, lint, build)
  • Slack MCP server pre-configured
  • Path-scoped edit permissions

CLAUDE.md Template

  • Development workflow steps baked in
  • Core principles as instructions
  • Corrections log ready to use
  • Customizable for any project or team
# Clone the repo
git clone https://github.com/jbellsolutions/boris-cherny-claude-code.git

# Install into your project
cd boris-cherny-claude-code && ./setup/install.sh /path/to/your/project

# Or install globally
./setup/install.sh --global

# Open Claude Code — everything is ready
claude
