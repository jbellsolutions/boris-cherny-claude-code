Core Principles

The three rules that make everything else work.

1

Verification Is Everything

Every workflow, agent, and command is built around giving Claude a feedback loop — tests, type checks, browser testing, CLI output. This 2-3x the quality of results.

2

Plan First, Execute Second

Start every complex session in Plan Mode. A good plan leads to 1-shot implementations. When things go sideways, re-enter Plan Mode instead of pushing forward.

3

Don't Accept the First Answer

Push Claude to do better. "Scrap this and implement the elegant solution." Challenge it. Demand proof. Claude can almost always do better when you raise the bar.

Key Workflows

How Boris actually uses Claude Code day-to-day.

P

Parallel Sessions

10-15 sessions simultaneously. 5 terminal tabs + 5-10 web sessions + phone. System notifications for status. Color-coded tabs. Named sessions for tracking.

W

Git Worktrees

Each session gets its own worktree — isolated branches that don't clobber each other. claude -w my-feature creates a worktree and starts a session.

R

Multi-Agent Code Review

5 subagents check logic, security, performance, style, edge cases in parallel. Then 5 more challenge the findings. Only real bugs with file:line survive.

L

Loop & Schedule

/loop 5m /babysit auto-addresses PR reviews. /schedule daily runs cloud jobs that survive laptop closure. Replace cron with Claude.

M

MCP Integrations

Slack bug thread → paste → "fix". BigQuery queries in natural language. Sentry errors pulled automatically. Zero context switching.

T

Teleport & Mobile

Start in terminal → teleport to web → continue on phone → teleport back. Code from anywhere. "When I'm not coding, I'm dispatching."
