# Boris Cherny's Claude Code Masterclass

## Who is Boris Cherny?

Boris Cherny is the creator of Claude Code at Anthropic. Before Anthropic, he was an engineer at Meta. He built Claude Code from the ground up, and over 80% of Anthropic's engineers use it daily.

## What This Course Covers

This course teaches you exactly how Boris Cherny uses Claude Code — his personal setup, workflows, and the practices that make the Claude Code team at Anthropic dramatically more productive.

Boris's philosophy: **There is no one correct way to use Claude Code.** It's intentionally built so you can use it, customize it, and hack it however you like. Each person on the Claude Code team uses it differently.

That said, Boris's specific practices have been refined through building and dogfooding Claude Code every day. This course captures those practices.
